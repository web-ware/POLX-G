# POLX-G

لعبة استراتيجية كبرى تعمل بالكامل داخل المتصفح، بعالم خيالي مستقل.

## المزايا
- إنشاء دولة وقائد وعاصمة ومستوى صعوبة وتخصص بداية.
- خريطة تفاعلية تضم دولة اللاعب و9 دول منافسة تعمل بمنطق AI.
- اقتصاد: GDP، خزينة، تجارة، طاقة، نفط، فولاذ، غذاء.
- إدارة داخلية: تعليم، استقرار، دعم شعبي، استخبارات وبنية إنتاجية.
- قوات برية وجوية وبحرية مع استنزاف للحروب ونتائج للجبهات.
- دبلوماسية: تجارة، علاقات، تحالفات، حروب وهدنات.
- شجرة تقنيات من 8 أبحاث تؤثر مباشرة في الدولة.
- أحداث عالمية عشوائية تغيّر الموارد والاستقرار والاقتصاد.
- مرور الزمن كل 3 أشهر وتطور الدول المنافسة.
- أهداف انتصار متعددة: اقتصادي، علمي، إقليمي، استقرار أو بقاء طويل.
- خسارة عند انهيار الاستقرار/الدعم/الاقتصاد.
- أوامر نصية عربية سريعة.
- حفظ وتحميل عبر LocalStorage.
- تصميم متجاوب للهاتف والكمبيوتر.
- لا توجد مفاتيح API ولا خادم مطلوب.

## التشغيل
افتح `index.html` مباشرة، أو فعّل GitHub Pages على فرع `main`.

## ملاحظات
اللعبة تستخدم دولاً وشخصيات وعالماً خيالياً حتى تكون تجربة استراتيجية مستقلة وليست محاكاة لقرار سياسي حقيقي.
