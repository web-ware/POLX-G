# POLX-G

لعبة استراتيجية عالمية أونلاين مبنية بواجهة HTML/CSS/JS مع Firebase Realtime Database.

## التشغيل

1. أنشئ Firebase Web App.
2. فعّل Anonymous Authentication.
3. أنشئ Realtime Database.
4. ضع إعدادات Web App داخل config.js.
5. طبّق database.rules.json.
6. فعّل GitHub Pages.

## المزايا

- دخول بكود دولة.
- مشاهدة العالم بدون امتلاك دولة.
- إنشاء دولة باختيار أرض واسم وحاكم ولون.
- مزامنة مباشرة بين الأجهزة.
- اقتصاد وخزينة وسكان ورضا واستقرار وجيش وصناعة وهيبة.
- علاقات وتجارة وتحالفات ومساعدات ونفوذ وصراعات داخل محاكاة اللعبة.
- نهاية أدوار وفصول وأحداث عالمية.
- واجهة متجاوبة للهواتف.

## ملاحظة

هذه نسخة MVP للاختبار مع الأصدقاء. نظام الصلاحيات يحتاج تشديداً ونقل الأوامر الحساسة إلى Backend قبل نشر اللعبة للعامة.
