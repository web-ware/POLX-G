# POLX-G

لعبة محاكاة سياسية واستراتيجية تعمل بالكامل داخل المتصفح.

## التشغيل
افتح `index.html` مباشرة، أو فعّل GitHub Pages على فرع `main`.

لا تحتاج اللعبة إلى API key أو خادم خارجي.

## الأنظمة
- إنشاء دولة وحاكم ونظام حكم وحقبة وصعوبة.
- الاقتصاد والاستقرار والشعب والدفاع والدبلوماسية والخدمات.
- خزينة وسكان وحالة حرب.
- أحداث دورية بقرارات متعددة ونتائج مختلفة.
- أوامر نصية مباشرة.
- مرور الزمن كل ثلاثة أشهر.
- حفظ وتحميل عبر LocalStorage.
- واجهة عربية متجاوبة مع الهاتف.

## التوسعة
المحرك محلي، ويمكن لاحقاً إضافة دول وأحداث وسياسات وعلاقات دولية أعمق دون كشف أسرار في المتصفح.
