# POLX-G AI

واجهة دردشة ويب عربية مبنية بدون framework وتستخدم Gemini API.

## التشغيل
1. افتح الموقع.
2. من ⚙️ أدخل مفتاح Gemini API.
3. اختر الموديل واضغط حفظ.
4. ابدأ الدردشة.

المفتاح لا يُحفظ في المستودع؛ يتم تخزينه في Local Storage في متصفح المستخدم فقط.

مهم: لا تضع مفتاح Gemini داخل ملفات JavaScript أو HTML في مستودع عام. للاستعمال الإنتاجي، الأفضل وضع API خلف خادم أو وظيفة serverless مع متغير بيئة سري.

واجهة Gemini تستخدم REST generateContent وفق توثيق Google AI.
